# Aturan proyek

## Tampilan antarmuka

- Semua pembuatan dan perubahan tampilan wajib menggunakan Tailwind CSS, sesuai instruksi pengguna tanggal 9 September 2026.
- Jangan membuat tampilan HTML biasa tanpa styling Tailwind, termasuk halaman contoh dan pratinjau pengujian.
- Gunakan komponen React/Inertia dan pola komponen proyek yang sudah tersedia, dengan utility class Tailwind untuk styling.
- Elemen HTML semantik di dalam JSX tetap diperbolehkan; aturan ini mewajibkan penggunaan Tailwind untuk tampilan, bukan melarang elemen HTML sebagai struktur komponen.


## Cascading production 2024–2026

- Pengguna meminta pada 17 September 2026 agar persiapan cascading 2024–2026 diingat untuk eksekusi production ketika diminta nanti.
- Sebelum menangani permintaan tersebut, baca `docs/CASCADING-PRODUCTION-2024-2026.md` dan `docs/CASCADING-2024-2026.md`.
- Acuan terbaru: 2024 dan 2025 memakai salinan data lama yang sama dan berstatus ditutup; 2026 memakai `docs/CASCADING.xlsx` dan menjadi periode aktif. Rencana 2027 sebelumnya telah digantikan.
- Verifikasi kondisi production, cadangkan, dan pertahankan batas tabel pada panduan. Jangan memakai ID lokal atau mengosongkan tabel untuk melewati prasyarat command.
- Permintaan menyimpan ingatan ini tidak menjalankan production; eksekusi dilakukan saat pengguna memintanya.
